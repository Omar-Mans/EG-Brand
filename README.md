# EG Brand: الـ MVP

منصة عربية بتدرس المشروع زي ما وكالة تسويق بتعمل، وبتكتبله استراتيجية 90 يوم، وبتبني هوية البراند على أساسها. بعد كده بتطلّع محتوى كل شهر وتجدوله وتنشره، وبتخطط الإعلانات، وبتحسب تكلفة الـ AI لكل شركة.

**الرحلة:** الدراسة ← الاستراتيجية ← الهوية ← المحتوى ← النشر ← الإعلانات

**النشر أونلاين ببلاش:** شوف [DEPLOY.md](DEPLOY.md).

## الستاك

| الطبقة | التقنية |
|---|---|
| Frontend | Next.js 15 + React 19 + TypeScript، والواجهة كلها عربي RTL |
| Backend | Python 3.13 + FastAPI + SQLAlchemy 2 |
| قاعدة البيانات | PostgreSQL، أو SQLite للتجربة السريعة |
| الشغل في الخلفية | Worker بيقرا طابور المهام من Postgres (`SKIP LOCKED`): توليد الـ AI والنشر المجدول |
| AI | LiteLLM كـ gateway: سلسلة fallback بين الموديلات، وتسجيل التوكنز والتكلفة لكل شركة، وحد ميزانية شهري |
| التصميم | الشعارات والبوستات بتترسم بالكود على canvas بخطوط عربية حقيقية، فمفيش حروف مشوّهة |
| النشر | Meta Graph API لـ Facebook و Instagram، وربط تجريبي (mock) لباقي المنصات |
| الإعلانات | Meta Marketing API: الحملة بتتعمل **موقوفة**، فمفيش صرف من غير موافقة صاحب الحساب |
| التخزين | محلي، أو S3 / Cloudflare R2 |

```
frontend/ (Next.js)  ──►  backend/app/main.py (FastAPI)
                              ├── routers/   auth · brands (+ discovery/strategy) · posts · social · ads · usage · jobs
                              ├── ai/        llm.py (gateway) · prompts.py · services.py · discovery.py · website.py · images.py · occasions.py · mock.py
                              ├── social/    meta.py · publisher.py
                              ├── jobs.py    طابور المهام + النشر المجدول
                              └── worker.py  python -m app.worker
```

## التشغيل محلياً

### الطريقة 1: Docker
```bash
cp backend/.env.example backend/.env   # اختياري: حط مفاتيح الـ AI و Meta
docker compose up --build
```
الواجهة على http://localhost:3000، والـ API على http://localhost:8000/docs

### الطريقة 2: من غير Docker
```bash
# Backend
cd backend
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --port 8000     # الـ worker شغال جوه الـ API (EMBEDDED_WORKER=true)

# Frontend (في terminal تاني)
cd frontend
npm install
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev
```

**عندك `.env` قديم؟** شغّل `powershell -ExecutionPolicy Bypass -File scripts\update-env.ps1` (Windows). بيضيف الإعدادات الجديدة الناقصة من غير ما يلمس مفاتيحك.

**من غير أي مفاتيح** كل حاجة شغالة: الـ AI بيرجّع بيانات تجريبية ثابتة، والحسابات بتتربط ربط تجريبي. ده مناسب للتطوير والـ tests.

### تشغيل الـ AI الحقيقي
حط مفتاح واحد على الأقل في `backend/.env` (مثلاً `GROQ_API_KEY` أو `ANTHROPIC_API_KEY`)، وظبط الموديلات:
```
LLM_FAST_MODELS=groq/openai/gpt-oss-20b
LLM_QUALITY_MODELS=groq/openai/gpt-oss-120b,groq/qwen/qwen3.8-27b
```
- Groq بيغيّر الموديلات المتاحة باستمرار. اعرف المتاح على حسابك من `https://api.groq.com/openai/v1/models`.
- كل سلسلة بتتجرب بالترتيب: لو موديل وقع، الطلب بيروح للي بعده.
- لو LiteLLM ما يعرفش سعر موديل، حط سعره في `LLM_PRICE_OVERRIDES`، وإلا التكلفة هتتسجل صفر.

### صور الخلفية للتصميمات
| الزرار | المصدر | التكلفة |
|---|---|---|
| ارفع صورتك | صور منتج العميل الحقيقية | مجاني، وأحسن نتيجة |
| صورة حقيقية | Pixabay (`PIXABAY_API_KEY`)، أو Pexels لو معاك مفتاح قديم | مجاني، والاستخدام التجاري مسموح، وبيتحفظ اسم المصور |
| صورة بالـ AI | Cloudflare Workers AI بموديل FLUX (`CF_ACCOUNT_ID` و `CF_API_TOKEN`) | حصة يومية مجانية |
| صورة بالـ AI | fal.ai (`FAL_KEY`) | مدفوع، حوالي 0.003$ للصورة |
| صورة بالـ AI | Pollinations، من غير أي مفتاح | للتجربة بس |

لما تعمل "صور لكل البوستات"، الصور بتتعمل بس للبوستات اللي شكلها فيه صورة. البوستات اللي اتصممت كعنوان جريء أو عرض بتفضل زي ما هي.

### استوديو الريلز (تبويب "الريلز" في كل براند)
- **ريل كامل من الـ AI (من غير تصوير):**
  - بتكتب الموضوع وتختار المدة (15 أو 30 أو 60 ثانية) والصوت.
  - الـ AI يكتب المشاهد، ويجيب **لقطات فيديو حقيقية** من Pixabay (نفس المفتاح المجاني) أو Pexels.
  - المونتاج بيبقى بإيقاع تختاره (هادي، سريع، سينمائي)، والقص على إيقاع الموسيقى، ونفس تظبيط الألوان على كل اللقطات.
  - الكلام اللي بيتقال بيتكتب على الفيديو كترجمة.
  - تقدر تغيّر أي لقطة، أو ترفع فيديو أو صورة من عندك لأي مشهد.
- **سكريبت وصوّر بنفسك:**
  - الـ AI يكتب سكريبت بلهجتك ومظبوط على المدة، أو يظبط السكريبت بتاعك: خطّاف، وسطور قصيرة، وختام.
  - بتقراه من **شاشة التلقين**: سرعة وحجم خط بتتحكم فيهم، ومرآة، وعدّ تنازلي.
  - تقدر **تصوّر من نفس الشاشة** بكاميرا الموبايل الأمامية، والكلام قريب من العدسة.
  - اللقطات بتتحفظ للخطوة الجاية: مونتاج الفيديو المتصور.

### الريلز (فيديو بصوت عربي وموسيقى)
1. **السكريبت:** الـ AI بيكتب 3 لـ 5 مشاهد. أول مشهد خطّاف، وكل مشهد ليه كلام على الشاشة وجملة بتتقال، بلهجة الصوت اللي اخترته.
2. **الصور:** كل مشهد ليه صورة. ينفع تكون صورة حقيقية، أو صورة بالـ AI، أو صورة العميل. الصورة المربعة أو العريضة بتظهر كاملة فوق نسخة مغبّشة منها، فالمنتج ما يتقصش.
3. **الصوت:** 4 أصوات (سعودي رجل وست، ومصري رجل وست)، أو من غير صوت.
   - **من غير أي مفتاح:** بيستخدم الأصوات المجانية بتاعة Microsoft Edge. دي خدمة مش رسمية، فاستخدمها للتجربة والديمو بس.
   - **للعملاء:** حط `AZURE_SPEECH_KEY`. ده نفس الأصوات بالطريقة الرسمية، وفيه free tier.
4. **الموسيقى:** 3 مقطوعات هادية متولّدة جوه المنصة نفسها، فمفيش أي مشكلة حقوق. أو من غير موسيقى، أو العميل يرفع موسيقاه وهو مسؤول عن حقوقها.
5. **الفيديو:** ffmpeg بيركّب حركة كاميرا بطيئة على الصور، والكلام العربي (مرسوم في المتصفح بالخطوط الحقيقية) بيدخل بحركة، ومعاه انتقالات بين المشاهد ومشهد أخير فيه الشعار والدعوة. النتيجة MP4 بمقاس 1080×1920 بصيغة H.264 + AAC، وده المطلوب لـ Reels.
6. **النشر:** الريل المعمول بيتنشر كفيديو. على انستجرام كـ Reel، وعلى فيسبوك كفيديو على الصفحة.

### الدراسة والاستراتيجية
- **الدراسة:** 27 سؤال في 6 أقسام، وزيهم بالظبط اللي بتسألهم أي وكالة: البيزنس، العميل، المنافسين، التسويق الحالي، الأهداف والميزانية، الشخصية. الأسئلة الأساسية 6 بس.
- **قراءة الموقع:** لو العميل حط رابط موقعه، المنصة بتقراه. فيه حماية بتمنع قراءة أي عنوان داخلي أو private.
- **أسئلة مخصوصة:** الـ AI بيكتب 4 أسئلة متابعة على حسب المجال.
- **الاستراتيجية:** التشخيص (SWOT)، والتموضع، والعملاء المستهدفين، والمنصات ودور كل واحدة، وأعمدة المحتوى، والميزانية، وخطة 3 شهور، وأول 7 أيام، والمؤشرات، والمنافسين، والمخاطر. وبتتحمّل PDF.
- **ممنوع أرقام متألفة:** الأهداف بتتحسب من الرقم اللي العميل قاله.
- الإجابات والاستراتيجية بيدخلوا في كل prompt بعد كده: الهوية، وخطة الشهر، والـ Agent، والإعلانات.
- عدد بوستات الشهر بيمشي على عدد البوستات في الأسبوع اللي في الاستراتيجية.

### ربط Meta بالتوكن (من غير مراجعة)
تطبيق Meta وهو في Development mode بيشتغل لأي صفحة صاحبها ليه دور في التطبيق (Admin أو Developer أو Tester):
1. ضيف حساب Facebook بتاع العميل كـ Tester من **App Roles** في تطبيق Meta.
2. من [Graph API Explorer](https://developers.facebook.com/tools/explorer/) اختار التطبيق، وضيف الصلاحيات: `pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish, business_management`.
3. اضغط **Generate Access Token**، وبعدها الصق التوكن في المنصة من صفحة **الحسابات**، في جزء "اربط صفحتك بالتوكن".
4. لو `META_APP_ID` و `META_APP_SECRET` متظبطين، المنصة بتحوّل التوكن لتوكن طويل المدى، وتوكن الصفحة الناتج ما بيخلصش لوحده.

### تشغيل النشر الحقيقي على Meta (لأي عميل من غير ما تضيفه)
1. اعمل App على developers.facebook.com وضيف Facebook Login.
2. ضيف الـ Redirect URI: `{PUBLIC_BASE_URL}/api/social/meta/callback`
3. اطلب الصلاحيات دي في App Review: `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `instagram_basic`, `instagram_content_publish`, `business_management`, `ads_management`, `ads_read`.
4. حط `META_APP_ID` و `META_APP_SECRET` في `.env`.
5. **Instagram بينزّل الصورة من رابط عام**، فلازم `STORAGE_BACKEND=s3` مع bucket عام (R2 مثلاً). `localhost` مش هينفع.

## الـ Tests
```bash
cd backend && . .venv/bin/activate && python -m pytest -q
```
بتغطي الرحلة كاملة: تسجيل ← براند ← هوية ← خطة الشهر ← تعديل واعتماد ورفع التصميم ← جدولة ← الـ worker ينشر ← خطة إعلانية ← التكلفة. وكمان عزل الشركات عن بعض، وحد الميزانية، والـ fallback وحساب التكلفة في مسار الـ AI الحقيقي.
